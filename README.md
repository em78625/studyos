🎓 StudyOS
StudyOS is a modern AI-powered study planning platform designed to help students organise their academic life, manage deadlines, track productivity, and improve learning outcomes.

🚀 Features
📚 Smart Study Planner
Create subjects and courses
Add study sessions
Schedule revision blocks
Manage deadlines
🤖 AI Study Assistant
Generate study schedules
Recommend revision sessions
Create daily study plans
Suggest focus areas
📊 Progress Analytics
Study hour tracking
Weekly reports
Subject performance monitoring
Productivity trends
✅ Task Management
Assign priorities
Mark tasks complete
Track assignments
Deadline reminders
🌙 Modern Dashboard
Dark mode
Responsive layout
Mobile support
Clean user experience
